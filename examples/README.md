# GitHub CLI Examples

This directory contains example scripts and code snippets demonstrating how to use the GitHub CLI (`gh`) in various scenarios.

## Examples

### 1. Basic Usage (`basic-usage.sh`)
Simple examples of common `gh` commands for everyday tasks.

### 2. Automation (`automation-workflow.sh`)
Demonstrates how to use `gh` in CI/CD pipelines and automation workflows.

### 3. API Integration (`api-examples.sh`)
Shows how to interact with GitHub's API using `gh api`.

## Running Examples

All example scripts are standalone and can be run directly:

```bash
# Make executable
chmod +x examples/basic-usage.sh

# Run the example
./examples/basic-usage.sh
```

## Prerequisites

- GitHub CLI (`gh`) installed
- Authenticated with GitHub (`gh auth login`)
- Access to a GitHub repository (for some examples)

## Contributing

Feel free to add more examples! Follow these guidelines:
- Keep examples focused on a single concept
- Add comments explaining what each command does
- Include error handling where appropriate
- Test your examples before submitting
